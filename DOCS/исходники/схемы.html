Путь поста

Файлы не удаляются и не копируются — только переносятся из папки в папку

1 · Запас
TEXT · PHOTO · VIDEO
TEXT/2026-11-01_unitree-g1.md PHOTO/2026-11-01_unitree-g1.jpg VIDEO/2026-11-05_factory.mp4
тексты и медиа уникальны для своей сети и проекта
→prepare + check: лимиты сети, ссылка, уникальность
2 · Очередь
READY
2026-11-01_0900_unitree-g1/ post.md текст поста photo.jpg фото meta.yaml (необязательно)
имя = дата и время выхода, поэтому папка сама по себе — расписание
→publish по расписанию, затем archive
3 · Архив
PUBLISHED
2026-11/ 2026-11-01_0900_unitree-g1/ post.md · photo.jpg info.json дата, время, ссылка, кто
по архиву проверяем, что темы и фото не повторяются
Карусель и сторис
медиа по порядку: 01.jpg, 02.jpg, 03.mp4 …
Видео
video.mp4 + обложка cover.jpg; хранится в Git LFS и никогда не удаляется
info.json
published_at · url · post_id · published_by (script / claude / chatgpt / user)

Кнопка и смена агента

Переключили — новый агент продолжает с того же места, контент и функции не теряются

1
Нажать кнопку
GitHub → Actions → «Переключить агента» → Run workflow → выбрать claude / chatgpt / none. Можно с телефона
2
Записывается
CONTROL/ACTIVE-AGENT.yaml: кто, с какого времени, кем; строка в JOURNAL/agent-switches.md
3
Новый агент читает
AGENT.md → TASKS/IN-WORK → JOURNAL за последние дни → продолжает. Старый агент больше ничего не меняет
▼задания движутся по папкам, после каждого шага — коммит
TASKS/INBOX
Новые задания
от пользователя или по плану: файл на задание
→
TASKS/IN-WORK
В работе
в файле: какой агент взял и когда
→
TASKS/DONE
Выполнено
итог и где лежит результат
JOURNAL/ГГГГ-ММ-ДД.md
каждое действие одной строкой: время · агент · что сделано. Это «память» системы — она не зависит от агента
