# AURA · THREADS — Threads

## Канал
Threads того же Instagram-аккаунта: @aura_robotics_ru (профиль Threads привязан к Instagram).

## Особенности сети
- Пост — до 500 символов (текст из Instagram не подходит, нужен свой). Карусель — до 20 элементов.

## Время публикаций
**Дубль Instagram** [формат утверждён 13.10.2026, дубль в плане — вместе с утверждением планов]: в то же время, что и в Instagram (Москва) — Reels → видео-пост,
карусель → карусель Threads (слайды те же, до 20). Сторис в Threads нет. Текст — свой, до 500 знаков, с хуком (ниже, «Правила проекта»); без `threads_text` публикатор ужимает подпись
Instagram сам (абзацы целиком, без хештегов, последней строкой aura-robotics.ru) или берёт поле `threads_text` из шапки.
В видеопостах нет «Листай карусель →»; у Reels-версии карусели в Threads только первый абзац (зацепка) и сайт —
полный текст уходит с каруселью, двух одинаковых длинных постов за день нет [13.10.2026].
Очередь — `THREADS/READY/<ГГГГ-ММ-ДД_ЧЧММ_тема>/post.md`; утверждённые посты Instagram попадают туда командой
`to_ready.py AURA/INSTAGRAM/<ФОРМАТ> --threads` (вместе с `--facebook`).

## Подключение
**Подключено 13.10.2026:** @aura_robotics_ru, приложение Meta «POST-HUB Publisher», секрет `THREADS_TOKEN_AURA` в POST-HUB, проверка `check` — «доступ есть», лимит 250 публикаций в сутки. Токен выпущен 13.10.2026, действует 60 дней — **обновить до 02.12.2026** (шаг 4 ниже → заменить секрет).
Генератор маркеров входит под тем аккаунтом Threads, который открыт в браузере: перед токеном второго аккаунта выйти из threads.net и instagram.com (или открыть окно инкогнито), иначе окно предложит «Продолжить как» первый аккаунт и выдаст его токен.

Публикатор POST-HUB — `CONTROL/TOOLS/net_threads.py` (Threads API, graph.threads.net). Доступ — секрет `THREADS_TOKEN_AURA`
(токен Threads, 60 дней — обновлять раз в ~50 дней). Токен получает пользователь, в чат и в файлы он не попадает:
1. Войти в Threads под Instagram-аккаунтом @aura_robotics_ru (если профиля Threads ещё нет — создать в приложении Threads).
2. developers.facebook.com → POST-HUB Publisher → Сценарии использования → «Доступ к Threads API» → Настроить →
   разрешения `threads_basic`, `threads_content_publish`.
3. Роли приложения → Роли → Добавить людей → «Тестировщик Threads» → профиль @aura_robotics_ru; принять приглашение:
   threads.net → Настройки → Аккаунт → Разрешения сайтов → Приглашения → Принять.
4. В сценарии «Доступ к Threads API» → Настройки → «Генератор маркеров пользователя» → «Сгенерировать маркер доступа» у @aura_robotics_ru
   → войти → скопировать токен (начинается с `THAA`).
5. POST-HUB → Settings → Secrets and variables → Actions → New repository secret: `THREADS_TOKEN_AURA`.
Проверить: Actions → «Публикация» → режим `check`.

## Правила проекта для этой сети
**Текст — свой, с хуком** [П, 13.10.2026: «Вот это уже лучше намного, делай публикацию»]. Подпись Instagram не ужимаем —
у каждого поста в шапке поле `threads_text` (до 500 знаков, на «вы», факты только из утверждённой подписи и слайдов):
- первая строка — хук с лёгкой иронией. Не «Хочу рассказать про свой проект» («нет никакой интриги», 13.10.2026).
  Образцы: «Ноги — это переоценено. Так решили в AgiBot и поставили гуманоида на колёса»; «Сотрудник, у которого обед
  длится ровно столько, сколько меняют батарею. То есть нисколько»;
- Reels (утро): хук → суть ролика в 1–2 строки (можно игра слов: «для цеха, где не развернуться») → проект одной строкой
  («Мы в Aura Robotics каждый день разбираем одну модель робота из Китая. Сегодня — этого парня») → вопрос читателю
  («Что бы вы доверили ему в первый рабочий день?») + «Пишите в ответ — подберём робота под задачу»;
- карусель (вечер): новый хук, не повтор утреннего → цифры списком → вопрос («Какой KPI вы бы ему поставили?»)
  + «подскажем, потянет ли он вашу задачу»;
- последняя строка — `🔗 https://aura-robotics.ru/ — выбрать робота под вашу задачу`.
Тексты показываются пользователю в макете ленты Threads и выходят только после его утверждения.
Общие правила проекта — `../RULES.md`.
