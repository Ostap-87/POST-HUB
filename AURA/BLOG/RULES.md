## Правила проекта для этой сети
- **Объём статьи и число подзаголовков — на усмотрение автора**: блог — площадка пользователя, здесь его правила [П, 10.10.2026]. (Прежняя норма редполитики «600–1000 слов, 3–6 подзаголовков» для блога не действует.)
- Подзаголовки — отдельными абзацами `## Подзаголовок`. [ЕП]
- Два языка: `title_ru/en`, `excerpt_ru/en`, `body_ru/en`; `publishedAt` — фактическая дата, не в будущем. [ЕП]
- **Обложка: `cover` + `coverCaption_ru` + `coverCaption_en` обязательно** — без подписи сайт скрывает картинку. [ЕП]
- 1–3 внутренние ссылки `[анкор](/catalog/<категория>/factory/<factoryId>)` прямо в тексте — анкор из слов самой статьи (название завода или модели), новых слов не добавляем [П, 10.10.2026]; ключевые слова — в заголовке, 1–2 подзаголовках и первом абзаце. [ЕП]
- Список источников в конце статьи — как у автора, **с адресами** [П, 10.10.2026]. Внутри текста внешний источник — названием, без гиперссылки. [ЕП]
- Действующая публикация: файл в `content/blog/` → `npm run sync && npm run build` → пуш в `main` AURA (деплой сам). [ЕП]

Общие правила проекта — `../RULES.md`.
