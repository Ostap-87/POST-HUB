# AURA · BLOG — Блог сайта

## Канал
https://aura-robotics.ru/blog — статьи в репозитории `Ostap-87/AURA`, файл на статью `content/blog/<slug>.json`.

## Особенности сети
- Полная статья и обложка. Посты в соцсетях опираются на статьи блога и ссылаются на них.

## Время публикаций
15:00 по Москве, в день из даты статьи [П] — решение пользователя 10.10.2026.

## Подключение
С 07.11.2026 — автоматически, без агента [П, 07.11.2026: «сделай так, чтобы статьи самостоятельно выходили без твоего участия»].
- Очередь — `AURA/BLOG/READY/<дата>_1500_<slug>/` (`post.ru.md`, `post.en.md`, `photo.jpg`), по статье в день; даты подряд — `python3 CONTROL/TOOLS/blog_site.py --project AURA --redate <дата>`, очередь — `--queue`.
- Публикует workflow «Блог из POST-HUB» репозитория `Ostap-87/AURA` (`.github/workflows/blog-from-post-hub.yml`): несколько раз в день берёт этот публичный репозиторий, запускает `blog_site.py --project AURA --due` и пушит статью и обложку (`public/covers/<slug>.jpg`) в ветку `main` — вебхук сервера пересобирает сайт. Одна статья вне очереди — Actions → «Блог из POST-HUB» → Run workflow → папка.
- Учёт — workflow POST-HUB «Блоги сайтов — учёт» (`blog-sites.yml`): вышедшие статьи уезжают в `PUBLISHED/ГГГГ-ММ/` с `info.json`.
- Стоп-кран — `CONTROL/PUBLISHING.yaml` (`AURA/BLOG` в `pause_except`).
- До 02–04.11.2026 статьи выкладывал сервер (claude-control, `/opt/publishers/publish-*-article.py`) из своей пачки — она закончилась.

## Правила проекта для этой сети
- **Объём статьи и число подзаголовков — на усмотрение автора**: блог — площадка пользователя, здесь его правила [П, 10.10.2026]. (Прежняя норма редполитики «600–1000 слов, 3–6 подзаголовков» для блога не действует.)
- Подзаголовки — отдельными абзацами `## Подзаголовок`. [ЕП]
- Два языка: `title_ru/en`, `excerpt_ru/en`, `body_ru/en`; `publishedAt` — фактическая дата, не в будущем. [ЕП]
- **Обложка: `cover` + `coverCaption_ru` + `coverCaption_en` обязательно** — без подписи сайт скрывает картинку. [ЕП]
- 1–3 внутренние ссылки `[анкор](/catalog/<категория>/factory/<factoryId>)` прямо в тексте — анкор из слов самой статьи (название завода или модели), новых слов не добавляем [П, 10.10.2026]; ключевые слова — в заголовке, 1–2 подзаголовках и первом абзаце. [ЕП]
- Список источников в конце статьи — как у автора, **с адресами** [П, 10.10.2026]. Внутри текста внешний источник — названием, без гиперссылки. [ЕП]
- Действующая публикация: файл в `content/blog/` → `npm run sync && npm run build` → пуш в `main` AURA (деплой сам). [ЕП]

Общие правила проекта — `../RULES.md`.
