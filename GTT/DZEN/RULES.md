# GTT · DZEN — Дзен

## Канал
«Командировка в будущее» — кросспостинг из Telegram GTT [статус уточнить: по редполитике канал настроен; в правилах сайта от 04.08.2026 — временно отключён].

## Особенности сети
- Посты из Telegram-канала Дзен может копировать сам (бот кросспостинга Яндекса); заголовок карточки — начало поста, обрезка примерно на 130–140 символах.
- В эту папку — отдельные статьи для Дзена, если будем их публиковать.

## Форматы
У каждого формата своя очередь: внутри формата папки TEXT, PHOTO, VIDEO, READY, PUBLISHED.

- `ARTICLE/` — статьи: длинный текст с иллюстрациями
- `POST/` — короткие посты; посты из Telegram-канала могут приходить сюда автоматически через бот кросспостинга
- `LONG/` — видео
- `SHORTS/` — ролики: короткие вертикальные видео
