## Форматы
У каждого формата своя очередь: внутри формата папки TEXT, PHOTO, VIDEO, READY, PUBLISHED.

- `POST/` — одно фото или одно видео в ленту; фото 4:5 (1080×1350), подпись до 2200 символов
- `CAROUSEL/` — пост из нескольких фото или видео (слайды), подпись до 2200 символов
- `REELS/` — вертикальное видео 9:16 с подписью
- `STORIES/` — фото или видео 9:16, исчезают через 24 часа; текст — на самом изображении

## Подключение
**Подключено 11.10.2026:** @globaltech_tour (бизнес-аккаунт), приложение Meta «POST-HUB Publisher», секреты `IG_TOKEN_GTT`, `IG_USER_GTT` в POST-HUB, проверка `check` — «доступ есть». Токен выпущен 11.10.2026, действует 60 дней — **обновить до 01.12.2026** (шаг 4 ниже → заменить секрет).

Публикация — через официальный API Instagram (вход через Instagram, `graph.instagram.com`); Facebook-страница не нужна.
Токен получает пользователь, в чат и в файлы он не попадает — только в секреты GitHub [П, 11.10.2026]:
1. Аккаунт — профессиональный (Настройки → Тип аккаунта и инструменты → Переключиться на профессиональный → Бизнес).
2. developers.facebook.com → Мои приложения → Создать приложение → сценарий «Управление сообщениями и контентом
   в Instagram» → тип «Бизнес».
3. В приложении: Роли приложения → Роли → Добавить людей → «Тестировщик Instagram» → аккаунт. Принять приглашение
   в Instagram (instagram.com → Настройки → Приложения и сайты → Приглашения тестировщика).
4. Instagram → «Настройка API со входом через Instagram» → «Создать маркеры доступа» → Добавить аккаунт → войти
   → разрешить публикацию. Скопировать токен (начинается с `IGAA`, живёт 60 дней) и ID аккаунта рядом с ним.
5. POST-HUB → Settings → Secrets and variables → Actions → New repository secret: `IG_TOKEN_GTT` (токен), `IG_USER_GTT` (ID).
Токен обновлять раз в ~50 дней (тот же шаг 4 → заменить секрет). Для своего аккаунта проверка приложения Meta (App Review)
не нужна: хватает роли тестировщика.
Проверить доступ: GitHub → Actions → «Публикация» → Run workflow → режим `check`.

**Как выходит пост** (`CONTROL/TOOLS/publish.py`, каждый час через GitHub Actions `publish.yml`, без агента):
1. Пользователь утверждает пост → в шапке `image_status` / `caption_status` (у сторис из роликов — `status`) = «утверждено».
2. `python3 CONTROL/TOOLS/to_ready.py GTT/INSTAGRAM/<ФОРМАТ> [--only <имя>]` переносит его в `READY/<имя>/`;
   картинки копируются в публичный VIDEO-HUB `finished-videos/publish/gtt-instagram/<имя>/` (Instagram берёт файлы
   только по публичной ссылке, POST-HUB закрытый), видео — по `video_hub` из VIDEO-HUB. Закоммитить и запушить оба репозитория.
3. В назначенное время публикатор проверяет ссылки и совпадение файлов с утверждёнными, публикует, переносит пост в
   `PUBLISHED/ГГГГ-ММ/` со ссылкой в `info.json`. Стоп-кран — `CONTROL/PUBLISHING.yaml` (`pause: true`).
