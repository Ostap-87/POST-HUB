## Правила проекта для этой сети
- Формат поста [ЕП]: жирный заголовок первой строкой `<b>…</b>` (40–70 символов), пустая строка, текст. Весь пост вместе с HTML-тегами — **до 1000 символов**, чтобы он ушёл одним сообщением «картинка + текст».
- Не тизер на два предложения, а развёрнутый мини-текст: конкретика, цифры, что это значит на практике. [ЕП]
- Первая строка — законченная мысль до 90–100 символов: в Дзене она становится заголовком карточки и обрезается на ~130–140 символах. [AURA-CP, SINOTECH]
- Картинка обязательна для каждого поста (JPG/PNG, не WebP); реальный логотип упомянутой компании — бейджем снизу слева. [ЕП]
- Темы: рынок китайских гигантов в отраслях, где у GTT есть тур (`sector` в `tours.json` SINOTECH), с реальными цифрами и названиями компаний. [ЕП]
- **09:00 — аналитический пост:** без ссылки и без закрывающей строки. **18:00 — продающий:** ссылка вшита в первой половине (`/expeditions/<tour_id>`, `/companies/<id>`, `/blog/<slug>`) + закрывающая строка (см. вопрос 1 в `../RULES.md`). [ЕП]
- Хэштеги в каждом посте: `#GTT #GlobalTechTour #Техтуризм` + 1–2 тематических/гео. [ЕП]
- Структура: инсайт из Китая/ЮВА → что это значит для бизнеса → как увидеть своими глазами (мягкий CTA). [SINOTECH]
- Обложку статьи для поста брать в `.png`, не `.webp`. [ЕП]
- Действующее расписание (claude-control): 09:00 и 18:00 МСК; понедельник 08:00 — дайджест; пятница 17:00 — сводка по рубрикам. Время в POST-HUB настроим позже.
