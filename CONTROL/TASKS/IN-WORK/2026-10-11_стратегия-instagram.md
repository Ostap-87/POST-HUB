## Автоматизация (11.10.2026)
- **Раскладка:** `GTT/INSTAGRAM/PLAN.json` + `python3 CONTROL/TOOLS/instagram_plan.py GTT --apply` → даты в именах, тексты
  Reels/Stories, анонсы, `GTT/INSTAGRAM/КАЛЕНДАРЬ.md`. Новый контент — дописать в `PLAN.json`, запустить заново.
- **Подписи под каруселями:** собираются из всех слайдов (`carousel_import.py GTT --captions`), 950–1430 знаков, 7 хештегов.
- **Публикация — сделано 11.10.2026** (решение пользователя: «управление универсальное, сейчас — чтобы ты мог начать публикации»):
  `CONTROL/TOOLS/publish.py` + `net_instagram.py` + `.github/workflows/publish.yml` (каждый час); файлы для Instagram —
  из публичного VIDEO-HUB (картинки копирует `to_ready.py`, видео — по `video_hub`), отдельный публичный репозиторий не нужен.
  От пользователя — только токен (секреты `IG_TOKEN_GTT`, `IG_USER_GTT`). Ниже — прежние варианты, для истории.
- *Было:* **Публикация — нужен выбор пользователя.** POST-HUB закрытый, а Instagram забирает картинки и видео только по публичной
  ссылке. Варианты: (1) свой публикатор в POST-HUB (GitHub Actions по расписанию 10:00 / 12:00 / 19:00): в момент выхода
  выкладывает файлы поста в публичное место и публикует через API, затем переносит в PUBLISHED; нужны секреты
  `IG_TOKEN_GTT`, `IG_USER_GTT` в POST-HUB и публичное место для файлов; (2) отдавать готовые посты в очередь MyFirst — она
  уже работает и публична, но это изменение MyFirst (сейчас его не трогаем) и там слоты только 10:00 и 19:00.
- **Музыка к каруселям:** через API нельзя (только Reels со своей звуковой дорожкой). Варианты: (а) карусели без музыки,
  полностью автоматически; (б) отдельные карусели публикует пользователь с телефона с музыкой из библиотеки Instagram —
  система присылает готовый набор (слайды + подпись) к времени выхода; (в) из карусели собирается Reels-слайдшоу с нашей
  лицензионной музыкой — выходит автоматически и закрывает пустые среды с недели 10.
