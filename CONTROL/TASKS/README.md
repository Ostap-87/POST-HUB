# Задания

- `INBOX/` — новые задания: файл на задание, имя `ГГГГ-ММ-ДД_кратко.md`.
- `IN-WORK/` — взято в работу. В файле: кто взял (агент) и когда.
- `DONE/` — выполнено. В файле: итог и где лежит результат.

Задание переносится из папки в папку, а не копируется. После каждого переноса — коммит и пуш.
