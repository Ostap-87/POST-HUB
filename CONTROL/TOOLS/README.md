# Команды пульта

Одинаковые для любого агента: агент вызывает команду — результат один и тот же, кто бы ни управлял.
Сейчас команды только описаны, логику добавим следующим шагом.

| Команда | Что делает |
|---|---|
| `queue` | показать очередь READY по всем проектам и сетям |
| `prepare` | собрать пост в READY из TEXT + PHOTO/VIDEO на нужную дату и время |
| `check` | проверить пост: лимиты сети, ссылка, уникальность против READY и PUBLISHED всех сетей |
| `publish` | опубликовать посты, время которых наступило (запускается по расписанию, без агента) |
| `archive` | перенести вышедший пост в PUBLISHED/ГГГГ-ММ/ и записать info.json (дата, время, ссылка) |
| `image-request` | заявка на картинку Higgsfield (генерация — только после согласия пользователя на цену) |
