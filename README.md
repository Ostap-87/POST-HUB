# POST-HUB

Автопубликация постов **GlobalTechTour** и **Aura Robotics** по расписанию — с 1 ноября 2026.
Каналы: Telegram, Instagram, блоги сайтов, Facebook и LinkedIn (через Make).
Правила для Claude — в [CLAUDE.md](./CLAUDE.md).

## Как это работает

1. Вы присылаете статьи (ноябрь–декабрь). Claude раскладывает их по папкам `посты/ГГГГ-ММ/ГГГГ-ММ-ДД-тема/`:
   статья для блога, версии под каждую соцсеть, дата, время, каналы.
2. Claude делает картинки в Higgsfield (16:9 и 4:5) — **только после того, как вы увидите цену и скажете «да»**.
   Картинки недели присылаются листом на согласование.
3. Вы одобряете неделю → у постов ставится `approved: true`.
4. GitHub сам запускает публикатор в часы публикаций. Порядок: статья в блоге → Telegram → Instagram → Make
   (Facebook и LinkedIn). Ничего не публикуется без одобрения.
5. После каждого запуска бот присылает вам отчёт в Telegram: что вышло, что нет.

Работает без открытой сессии Claude.

## Что нужно от вас

**Ключи** — только в GitHub: репозиторий → Settings → Secrets and variables → Actions → New repository secret.
В чат их не присылайте.

| Секрет | Где взять |
|---|---|
| `TG_BOT_TOKEN` | у @BotFather (можно тот же бот, что публикует сейчас); добавить бота админом в каждый канал |
| `TG_REPORT_CHAT` | ваш chat id — напишите боту, Claude подскажет, как узнать |
| `IG_TOKEN_*`, `IG_USER_*` | уже заведены в MyFirst — скопировать сюда те же значения |
| `MAKE_WEBHOOK_URL` | в Make: сценарий → модуль «Webhooks → Custom webhook» → скопировать адрес |
| `SITE_REPO_TOKEN` | GitHub → Settings → Developer settings → Fine-grained tokens: доступ «Contents: write» только к SINOTECH и AURA |

**Make:** один сценарий: Custom webhook → публикация в страницу Facebook и в LinkedIn → Webhook response.
Схему данных Claude пришлёт, когда дойдём до этого шага.

## Пауза и правки

- Снять один пост — поставить у него `approved: false` (или попросить Claude).
- Остановить всё — GitHub → Actions → Publish → Disable workflow.
- Поправить текст или время — изменить файл поста; изменения учитываются при следующем запуске.
