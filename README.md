# POST-HUB

Контент и публикации трёх проектов — **Aura Robotics**, **GlobalTechTour** и **ostapdotcenko** — во всех соцсетях.
Управлять репозиторием может любой агент (Claude, ChatGPT и др.); кто управляет сейчас — переключается кнопкой.

## Устройство

```
POST-HUB/
├── CONTROL/           пульт: инструкция для агентов, кнопка, задания, журнал, команды, общие правила роликов
├── AURA/              aura-robotics.ru
├── GTT/               globaltechtour.ru
└── OSTAPDOTCENKO/     личный сайт
```

В каждом проекте, кроме сетей:

```
AURA/
├── RULES.md       правила проекта
├── VIDEO.md       стиль роликов
└── BRAND/         брендбук BRAND.md, LOGO/, FONTS/, MASCOT/ (у Aura), TEMPLATES/
```

В каждом проекте 11 сетей — `TELEGRAM`, `DZEN`, `BLOG`, `FACEBOOK`, `LINKEDIN`, `INSTAGRAM`, `THREADS`, `X`,
`YOUTUBE`, `WECHAT`, `XIAOHONGSHU`, — и в каждой одинаковые папки:

```
TELEGRAM/
├── RULES.md       правила сети
├── TEXT/          запас текстов
├── PHOTO/         запас фото
├── VIDEO/         запас видео
├── READY/         очередь: готовые посты по дням (текст + фото или видео)
└── PUBLISHED/     архив вышедшего: по месяцам, с датой, временем и ссылкой
```

Instagram, Facebook, YouTube и Дзен разделены на форматы, у каждого своя очередь с теми же пятью папками:
Instagram — `POST`, `CAROUSEL`, `REELS`, `STORIES`; Facebook — `POST`, `REELS`, `STORIES`; YouTube — `LONG`, `SHORTS`;
Дзен — `ARTICLE`, `POST`, `LONG`, `SHORTS`.

Материал движется так: запас (TEXT, PHOTO, VIDEO) → READY → PUBLISHED. Файлы не удаляются, только переносятся.
Контент в каждом проекте и в каждой сети уникальный. Видео хранятся через Git LFS.

## Кнопка: кто управляет

GitHub → вкладка **Actions** → **«Переключить агента»** → **Run workflow** → выбрать `claude`, `chatgpt` или `none`.
Работает и из мобильного приложения GitHub. Текущий агент записан в `CONTROL/ACTIVE-AGENT.yaml`,
история переключений — в `CONTROL/JOURNAL/agent-switches.md`.

Агент, который не выбран, ничего не меняет. Новый агент продолжает с того же места: задания — в
`CONTROL/TASKS/`, что уже сделано — в `CONTROL/JOURNAL/`, контент — в папках проектов.

## Документы

- `DOCS/POST-HUB_архитектура-и-правила.docx` — подробное описание со схемами (Word).
- `DOCS/POST-HUB_промпт-для-агента.md` — универсальный промпт: вставить целиком в любого агента для быстрого старта.
- `DOCS/схемы/` — схемы картинками; исходники и сборка — `DOCS/исходники/` (`render-schemes.mjs`, `make-docx.js`).
- `DOCS/схемы/06-бренды-проектов.jpg` — лист-сравнение брендов трёх проектов (палитра, шрифты, логотипы, стиль роликов).

## Правила

- Для агентов — `CONTROL/AGENT.md` (вход через `CLAUDE.md` и `AGENTS.md`).
- Проект — `<ПРОЕКТ>/RULES.md`, брендбук — `<ПРОЕКТ>/BRAND/BRAND.md`, ролики — `<ПРОЕКТ>/VIDEO.md`,
  сеть — `<ПРОЕКТ>/<СЕТЬ>/RULES.md`.
- Общие правила роликов — `CONTROL/VIDEO-RULES.md`.
- Сейчас это черновики, собранные из действующих репозиториев; утверждаем вместе.
